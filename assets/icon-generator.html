The Mountain - App Icons

How to export these icons:

  1. Open this file in Chrome/Safari
  2. Right-click each icon and "Save Image As..."
  3. Save to your assets/ folder with the correct filename
  4. For 1024x1024 icon.png, you may need to take a screenshot and resize
